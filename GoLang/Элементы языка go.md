# var
Служит для объявления переменных. Если переменная неинициализорвана, var инициализирует ее неявно автоматически, присваивая нулевое значение

# for
Является единственной инструкцией цикла в Go
```go
for иницивлизация; условие; последействие {
	//нуль или несколько инструкций
}
```
Пример:
```go
for i := 0; i <= 100; i++{
	fmt.Println(i)
}
```
Выводит по одному в строке числа от 0 до 100 включительно
Любая из частей (инициализация, условие, последействие) может быть опущена.
