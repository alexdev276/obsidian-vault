| --------- | ---------------------- | ----------------------------------------------------------------------------------------------------- |
| [[#Args]] | переменная, срез строк | содержит название команды и аргументы, которые были переданы программе, в момент начала ее выполнения |
# Args
Первый элемент среза `os.Args[0]` представляет собой имя самой команды, остальные аргументы содержатся в срезе `os.Args[1:len(os.Args)]` или `os.Args[1:]` 
Пример:
``` go
package main

import (
	"fmt"
	"os"
)

func main() {
	var s, sep string
	fmt.Println(os.Args[0])
	for i := 1; i < len(os.Args); i++ {
		s += sep + os.Args[i]
		sep = " "
	}
	fmt.Println(s)
}
```

Запуск:
```bash
go build t.go
./t arg1 arg2 arg3
```

Результат:
```bash
./t
arg1 arg2 arg3
```
