Команда go

| Субкоманда           | для чего нужна                                          |
| -------------------- | ------------------------------------------------------- |
| run <имя файла>.go   | собрать и запустить программу (удаляет сбилженный файл) |
| build <имя файла>.go | собрать файл в <имя файла>                              |
Команда gofmt
Предназначение - приводит код к стандартному формату
Особенности
* сортирует подключаемые пакеты в алфавитном порядке
* ставит недостающие пробелы
* и тд
делает код читаемым
